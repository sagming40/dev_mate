### 2. 핵심 로직 흐름 (The Flow)

우리가 짠 코드는 크게 **3단계 인증**을 거쳐서 작동해.

1. **구글 단계:** 사용자가 계정을 선택하면 구글이 "이 사람은 사공민규가 맞다"라고 보증해 줘.

2. **변환 단계:** 구글이 준 보증서를 Firebase가 알아볼 수 있는 **`AuthCredential`** 형태로 바꿔.

3. **Firebase 단계:** 그 변환된 카드를 제출해서 Firebase 서버의 '승인'을 받아내고 앱 안으로 입장해!

---

### 3. 우리가 겪은 3대 난관 (War Stories)

민규가 삽질하며(?) 배운 진짜 지식들이야.

* **SHA-1의 저주:** 
안드로이드 개발의 첫 고비. 
`keytool`과 `signingReport`가 안 돼서 고생했지만, 
결국 윈도우 환경 변수와 `gradlew` 명령어로 신분증(지문)을 찾아냈지.

* **No Firebase App 에러:** 
`main()` 함수에서 `await`를 빼먹으면 
앱이 서버 연결도 안 된 상태에서 로그인을 시도하다가 빨간 화면을 띄운다는 걸 배웠어.

* **2026년 버전 지옥:** 
패키지 업데이트로 인해 예전 방식(`GoogleSignIn()`)이 안 먹힐 때, 
버전을 고정하거나 최신 문법으로 고치는 법을 익혔어.

### 4. 최종 코드의 "맛" 보기 (짧은 요약)

```dart
// 로그인의 핵심은 딱 이 3줄이야!
final googleUser = await GoogleSignIn().signIn();          // 1. 구글 호출
final googleAuth = await googleUser!.authentication;       // 2. 인증 획득
await FirebaseAuth.instance.signInWithCredential(...);     // 3. 서버 승인

```
